# Giselle Ulloa Digital

Create the official bilingual website and digital brand experience for Giselle Ulloa.

The website must be fully available in:

Spanish (ES)
English (EN)

Spanish and English must be treated as first-class languages from the beginning of the project.

This is a personal-led technology brand, not a generic marketing agency, freelancer portfolio, software factory, or AI-only consultancy.

The website must position Giselle as:
